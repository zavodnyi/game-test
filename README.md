# ДВОР — браузерная тестовая версия

[Играть в браузере](https://zavodnyi.github.io/game-test/)

Версия **1e47245**: исправленные нажатия по снарядам, отдельная нижняя панель, видимая экипировка с немедленным надеванием; ограниченный норматив повторного отбора (до уровня 20 с нового сезона). Прогресс сохраняется в браузере.

Здесь находится готовая статическая сборка. История и исходные файлы основного проекта сюда не включены.

## Если сайт ещё не включён

В этом репозитории откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: gh-pages → /(root) → Save**. После завершения публикации откроется ссылка выше.

## Скачать для компьютера

[Скачать game-test.zip](https://github.com/zavodnyi/game-test/raw/refs/heads/main/game-test.zip) · 10.2 МБ.

Распакуйте архив и запустите `start-game.cmd`. Нужен Node.js, установка зависимостей не требуется. В macOS/Linux выполните `node start-game.cjs`. Откройте адрес, показанный в окне запуска.

[Страница скачивания](https://zavodnyi.github.io/game-test/download.html). Контрольная сумма находится в `game-test.zip.sha256`.
