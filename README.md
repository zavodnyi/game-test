# ДВОР — браузерная тестовая версия

[Играть в браузере](https://zavodnyi.github.io/game-test/?v=d149040)

Версия **d149040**: предметный интерфейс зала без нижнего меню. Наведение или касание подсвечивает снаряд и открывает окно тренировки рядом с ним. Характеристики на меловой доске; афиша, шкафчик и каталог открывают свои действия. Прогресс сохраняется в браузере.

Здесь находится готовая статическая сборка. История и исходные файлы основного проекта сюда не включены.

## Скачать для компьютера
