# ДВОР — браузерная тестовая версия

[Играть в браузере](https://zavodnyi.github.io/game-test/?v=65351cc)

Версия **65351cc**: каталог на стене, выбор снаряда с подтверждением тренировки, без прямоугольных обводок; разбор боя с фактами и советом. Исправлено заполнение ринга при смене сцены. Прогресс сохраняется в браузере.

Здесь находится готовая статическая сборка. История и исходные файлы основного проекта сюда не включены.
